Simple ECommerce

A simple Ecommerce made with React, with API PHP to manage the data, and MySQL database. The most difficult in this project, was in a low budget, using different ways to storage data. MySQL database, that storage the products, and the references to the images on IMGBB. On create new products, that compress to a low quality, and then, to upload to the IMGBB, that returns the URL of the image, and add to database.

Ecommerce Simples

Um ecommerce simples feito com React, com API PHP para gerenciar os dados, e banco de dados MySQL. O mais difícil nesse projeto foi o orçamento baixo, usando diferentes maneiras de armazenar dados. Banco de dados MySQL, que armazena os produtos, e as referências para as imagens no IMGBB. Ao criar novos produtos, as imagens são comprimidas para baixa qualidade e depois enviadas para o IMGBB, que retorna a URL da imagem e a adiciona ao banco de dados.

Spotify Downloader with Lyrics (in Work)

A simple Spotify Downloader made with web client, with API Spotify, to download the songs, and the lyrics. On server used nodeJS, FFmpeg is required for the ytdlp library. Server are on Docker container. Front-End made with React, and search by Spotify API. While, only works on playlists.

Spotify Downloader com Letras (em andamento)

Um simples Spotify Downloader feito com cliente web, usando a API do Spotify para baixar as músicas e as letras. No servidor, foi utilizado o nodeJS, e o FFmpeg é necessário para a biblioteca ytdlp. O servidor está em um contêiner Docker. O Front-End foi feito com React, e a busca é realizada pela API do Spotify. Por enquanto, funciona apenas em playlists.
